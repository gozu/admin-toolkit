Admin Toolkit — Security Setup

1 Master Admin Toolkit Password
This is the only password for Admin Toolkit. Used to encrypt Advanced Actions and API keys of every remote host. Write it down now — it is never stored or sent, so if you lose it, every secret here must be redone.
2 Advanced Actions secret

Paste into Plugin settings → “Advanced Actions password (hash)”.

3 Remote host API keys

Paste each blob into that host’s preset “API Key” field. One unlock opens them all.
