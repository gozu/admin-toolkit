Destructive Actions — password hash

Type the password you want to gate destructive actions with. This page derives a salted PBKDF2 hash entirely in your browser — the password is never sent anywhere. Paste the resulting hash into the Admin Toolkit plugin settings field “Destructive Actions password (hash)”.

Format: pbkdf2_sha256$<iterations>$<base64-salt>$<base64-derived>
Algorithm: PBKDF2-HMAC-SHA-256 · 600,000 iterations · random 16-byte salt · 32-byte key.
Offline-safe: this page makes no network requests. You can save it and open it from disk.
